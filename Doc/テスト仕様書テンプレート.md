## 正常系テスト（基本機能が動くか）

| ID | テスト観点 | 手順 | 期待結果 | 実際の結果 | 合否 |
| :---- | :---- | :---- | :---- | :---- | :---- |
| T01 | アプリが開く | ブラウザでURLを開く | 地図（大阪市周辺）が表示される |  |  |
| T02 | データが表示される | アプリを開く | kankou.csv・bunkazai.csv のピンが地図上に表示される |  |  |
| T03 | ポップアップが開く | ピンをクリックする | 施設名・住所などの情報がポップアップで表示される |  |  |
| T04 | カテゴリ分類表示（M-1） | カテゴリフィルターで「文化財」を選択する | 文化財（bunkazai.csv）のピンだけが地図上に表示される |  |  |
| T05 | ルート計算（M-2） | スタート地点とゴール地点を地図上で指定し、ルート計算を実行する | 複数の観光スポットを効率的に回る順番とルートが地図上に表示される |  |  |
| T06 | キーワード検索（M-3） | 検索バーに施設名の一部（例：「大阪城」）を入力して検索する | 入力キーワードに一致するピンだけが地図上に表示される |  |  |

## 異常系テスト（おかしな操作をしたら）

| ID | テスト観点 | 手順 | 期待結果 | 実際の結果 | 合否 |
| :---- | :---- | :---- | :---- | :---- | :---- |
| T07 | データがない区を選択 | 絞り込みでピンが存在しない区を選ぶ | 「0件」などの表示になり、地図が壊れない |  |  |
| T08 | 画面を小さくする | ブラウザ幅を半分にする | レイアウトが崩れず、地図・検索バー・ボタンが使える |  |  |
| T09 | 検索結果が0件のとき | 存在しないキーワード（例：「zzzzzz」）で検索する | ピンが消え、「見つかりません」などのメッセージが表示される（または地図が壊れない） |  |  |
| T10 | ルートのスタートとゴールが同じとき | 同じスポットをスタートとゴールに指定してルート計算を実行する | エラーメッセージまたは適切なフィードバックが表示され、アプリが止まらない |  |  |
